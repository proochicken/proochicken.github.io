Đây là bộ ghi chú học tập của mình về các chủ đề an toàn thông tin, từ reconnaissance, network scanning và enumeration đến web security, cloud và cryptography.

[Xem toàn bộ CEHv13 study notes trên GitHub](https://github.com/proochicken/CEHv13).

## Nhóm chủ đề

- Reconnaissance, network scanning và enumeration
- Vulnerability analysis, system hacking và malware threats
- Sniffing, denial of service, session hijacking và evasion
- Web server, web application, SQL injection và wireless security
- Mobile, IoT, cloud computing và cryptography
- Các ghi chú lý thuyết về subnetting, địa chỉ IP và phụ lục tham khảo
